<h1 align="center" dir="ltr">Eternal</h1>

<p align="center" dir="rtl">

## این فورک چه چیزی اضافه می‌کند

علاوه بر همه‌ی امکانات 3x-ui (پروتکل‌های VLESS و VMess و Trojan و Shadowsocks، همراه با REALITY، Hysteria2، TUIC، AmneziaWG، MTProto، چندنودی، اشتراک، ربات تلگرام و دیسکورد و API)، این پنل این‌ها را دارد:

**پروتکل‌های بیشتر**
- OpenVPN، ‏IKEv2/IPsec، ‏L2TP/IPsec، ‏SSTP (برای VPN داخلی ویندوز) و OpenConnect/AnyConnect
- اکانت تونل SSH با حجم و انقضا و محدودیت اتصال همزمان
- حسابداری حجم، سقف حجم، انقضا و قطع فوری اتصال برای همه‌ی این پروتکل‌ها

**فروش و صورتحساب**
- پلن‌ها، سفارش‌ها و صفحه‌ی خرید عمومی که ورود به پنل نمی‌خواهد
- کارت‌به‌کارت با تأیید ادمین، زرین‌پال، آیدی‌پی و NOWPayments برای پرداخت ارز دیجیتال
- کیف پول مشتری، کد تخفیف و پاداش معرفی
- اعتبار کیف پول نماینده، لیست قیمت عمده، گزارش فروش و انتقال کاربر بین نماینده‌ها

**عملیات و امنیت**
- نقش‌ها و دسترسی محدود هر ادمین، نشست‌ها، فهرست IP مجاز، قفل بعد از ورود ناموفق و کپچا
- هشدار ورود از IP یا کشور جدید، ورود با کد یک‌بارمصرف تلگرام و امضای لینک اشتراک
- بکاپ رمزنگاری‌شده و بکاپ زمان‌بندی‌شده روی پوشه‌ی محلی یا هر فضای سازگار با S3، با تقسیم فایل‌های بزرگ
- پشتیبانی از MySQL و MariaDB در کنار SQLite و PostgreSQL
- خروجی Prometheus و داشبورد آماده‌ی Grafana
- بررسی سلامت پنل، حالت تعمیرات، تشخیص اکانت اشتراکی و میانبرهای کیبورد

**ضد فیلترینگ و نودها**
- اسکنر IP تمیز Cloudflare، هشدار بسته‌شدن پورت و چرخش پورت و SNI
- قالب مسیریابی ایران با یک کلیک
- نصب نود با یک دستور و انتقال خودکار لینک اشتراک به نود پشتیبان وقتی نود خراب می‌شود
- تست سرعت نود، سقف ماهانه‌ی حجم و ثبت هزینه‌ی هر نود

**کاربران و اشتراک**
- قالب ساخت کاربر، نمودار مصرف روزانه، انتقال کاربر از Marzban و Marzneshin و Hiddify
- اکانت تست در ربات تلگرام و خروجی اشتراک برای sing-box و Outline و Surge و Quantumult X و Loon
- لینک اشتراک کوتاه، محدودیت نرخ درخواست و آمار دریافت اشتراک
- دستور `eternal client` برای اسکریپت‌نویسی

**اعلان‌ها**
- وبهوک، ntfy، Gotify، Slack، بله، متن‌های قابل ویرایش ربات، خلاصه‌ی هفتگی و هشدار حجم و انقضا

**ظاهر**
- رابط کاملاً بازطراحی‌شده با صفحه‌ی ورود جدید، ویجت‌های داشبورد، تنظیمات برندینگ، لاگ فعالیت ادمین، مدیریت اعلان‌ها و سایت فریب برای بازدیدکننده‌های ناشناس
- ۱۳ زبان با تم تیره و روشن و پشتیبانی کامل از راست‌به‌چپ

## نصب

اسکریپت نصب و به‌روزرسانی فایل‌ها را از Releaseهای همین مخزن در گیت‌هاب می‌گیرد (با workflow انتشار ساخته می‌شود)، پس اول یک Release منتشر کنید یا از سورس بسازید.

</div>

```bash
bash <(curl -Ls https://raw.githubusercontent.com/rad1in/eternal/main/install.sh)
```

<div dir="rtl">

هنگام نصب نام کاربری، رمز و مسیر دسترسی تصادفی ساخته می‌شود. بعد از نصب دستور `eternal` را بزنید تا منوی مدیریت باز شود.

### ساخت از روی سورس

نیازمندی‌ها: Go (نسخه‌ی `go.mod`)، یک کامپایلر C (درایور SQLite به CGo نیاز دارد) و Node نسخه‌ی ۲۶ برای فرانت‌اند.

</div>

```bash
cd frontend && npm ci && npm run build && cd ..
go build -o eternal .
```

<div dir="rtl">

### داکر

</div>

```bash
docker compose up -d
```

<div dir="rtl">

## پایگاه داده

SQLite (پیش‌فرض)، PostgreSQL و MySQL/MariaDB. انتخاب با متغیرهای محیطی انجام می‌شود که نصب‌کننده در `/etc/default/eternal` می‌نویسد:

</div>

```
XUI_DB_TYPE=postgres        # sqlite | postgres | mysql
XUI_DB_DSN=postgres://user:password@127.0.0.1:5432/db?sslmode=disable
```

<div dir="rtl">

دستور `eternal migrate-db --dsn "<dsn>"` پایگاه SQLite موجود را به PostgreSQL یا MySQL منتقل می‌کند.
