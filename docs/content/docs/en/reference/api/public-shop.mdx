title: Public Shop
description: 'The customer-facing purchase API. It needs no panel session: a
  customer holds only the order token. It lives at /shop/api, outside the panel
  base path, and answers 404 (or the decoy site) until the shop is switched on
  in the sales configuration. Refusals come back as success false with a stable
  code in msg (plan_unavailable, invalid_email, invalid_kind, email_taken,
  email_unknown, gateway_unavailable, order_not_found, order_state,
  receipt_invalid, currency_unsupported, gateway_failed, bad_signature,
  amount_mismatch, discount_invalid, discount_used, referral_invalid,
  wallet_insufficient, proof_invalid); rate_limited arrives with HTTP 429 and
  internal_error with 500. Writes are limited to 30 per 10 minutes per address.'
