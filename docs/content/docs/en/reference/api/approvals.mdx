title: Approvals
description: "Two-person approval. When the owner gates an action in Settings →
  Security → Extra protection, a request for it is parked here instead of
  running, and a different owner or admin must approve it. Gateable actions:
  inbound.delete (single and bulk inbound delete), clients.bulkDelete,
  node.delete. The gate is off while no second owner or admin exists. Requests
  expire after 24 hours; every request and decision is written to the activity
  log. A master panel's node-sync pushes are never parked. All endpoints under
  /panel/api/approvals."
